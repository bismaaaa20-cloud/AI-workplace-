## Workflow
Read the current handoff and relevant project notes first. Select one executor per task, agree on scope and acceptance criteria, work only in the assigned repository and branch, report checks actually run, and leave a concise handoff. The owner makes final decisions and approves merges.

## Security and privacy
This repository is public. Treat every committed file, issue, pull request, commit message, and workflow log as public. Never store API keys, tokens, passwords, private conversations, personal data, or confidential information here.

## Important limitation
These files coordinate people and assistants; they do not create automatic ChatGPT-to-AI-Cloud messaging or grant either assistant access to another assistant's account. Any integration requires a separately designed, authenticated, least-privilege implementation and explicit owner approval.
