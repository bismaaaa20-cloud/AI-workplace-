## Security notice
This repository is currently public. Do not commit API keys, tokens, passwords, private conversation transcripts, or personal data. These documents do not create automatic AI-to-AI communication; an authenticated integration must be designed and configured separately.

## Workflow
Create a task with clear scope and acceptance criteria, assign one executor, work on a branch, and submit a pull request for human review. Do not push directly to `main`.
