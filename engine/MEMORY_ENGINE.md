# UAWA Memory Engine

## Memory classes
- **Personal AI memory:** an AI identity's own useful work notes, lessons, goals, and changelog. Different work surfaces may map to one identity, but sharing is never assumed.
- **Shared memory:** durable, public-safe facts and owner-approved decisions intentionally made available to authorized workplace participants.
- **Project knowledge:** sourced research with date, confidence, and project scope.
- **Session handoff:** progress, blockers, and next action for a specific work surface/session.
- **Private Master Prompt Vault:** storage-only archive of prompts owned by an AI identity. Other AI identities cannot read or follow its contents; prompts are not automatically loaded or executed.

## Save procedure
1. Classify information and check sensitivity, necessity, source, accuracy, and retention value.
2. Reject credentials, secrets, private prompts, and private chat transcripts from this public repository.
3. Write personal notes only to that AI identity's approved private storage. Do not use public repository folders as if they were private.
4. Submit shared-memory changes as proposals for owner approval.
5. Store master prompts only in a genuinely private vault with deny-by-default access. Do not add prompt content to shared memory.
6. Label uncertain claims UNVERIFIED and stale material OUTDATED.
7. Record source, date, AI identity, work surface, and reason where useful, without exposing private content.

Public repository folders are not private access boundaries. This document describes policy; it does not technically enforce authentication or encryption.
