# UAWA Memory Engine

## Memory classes
- Personal notebook: an agent's own useful work notes, lessons, goals, and changelog.
- Shared memory: durable, public-safe facts and owner-approved decisions.
- Project knowledge: sourced research with date, confidence, and scope.
- Session handoff: progress, blockers, and next action.

## Save procedure
1. Classify information and check sensitivity, necessity, source, accuracy, and retention value.
2. Reject credentials and secrets. Do not store private chat transcripts or unnecessary personal data.
3. Write personal notes only to the agent's own notebook through repository workflow.
4. Submit shared-memory changes as proposals for owner approval.
5. Label uncertain claims UNVERIFIED and stale material OUTDATED.
6. Record source, date, agent, and reason where useful.

Public repository folders are not private access boundaries.
