# UAWA Conflict Engine

- Hierarchy conflict: follow the higher rule; reject only the conflicting portion if separable.
- Same-level conflict: pause affected work and ask owner.
- Permission conflict: do not act; request required access or direction.
- Evidence conflict: compare source authority, date, scope, and provenance; preserve uncertainty.
- Agent disagreement: record positions and evidence; seek review and owner decision when consequential.

Record material conflicts without secrets.
