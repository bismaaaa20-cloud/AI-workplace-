# UAWA Bootstrap Protocol

At each new session or assigned task:
1. Read README.md and AI_ONBOARDING.md.
2. Read constitution/HIERARCHY.md and applicable constitutional documents.
3. Read applicable governance and system protocols.
4. Read own notebook and registry entry, if available.
5. Read HANDOFF.md, assigned task, relevant project rules, and approved decisions.
6. State which sources were actually accessible.
7. Summarize current state, scope, constraints, approval gates, and next action before consequential edits.

If access is unavailable, ask the owner for relevant public-safe content. Never pretend context was loaded.
